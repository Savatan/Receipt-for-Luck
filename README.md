# Чек на удачу

Веб-приложение для регистрации и проверки кассовых чеков в рамках промоакции.

Пользователь может зарегистрировать чек, отслеживать его статус и просматривать историю в личном кабинете. Модератор проверяет чеки, указывает причину отказа и выгружает принятые записи в CSV. Доступ к данным ограничен текущим пользователем.

**Стек:** Python · Django · PostgreSQL · HTML · CSS · JavaScript · Docker Compose
